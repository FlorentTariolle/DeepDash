Annealed Structured Label Smoothing for Discrete World Models

Tokenizer-metric-aware soft targets stabilize discrete world-model training early, then anneal back to cross-entropy for unbiased late optimization.

Current evidence

Annealing keeps the useful part of smoothing

The first matched IRIS/Pong run supports a stability and sample-efficiency claim: annealed SLS improves the unstable CE training window while recovering near-CE final return. Multi-seed CE vs. annealed-SLS runs are in progress.

Unstable-window mean return +7.16
Eval-return AUC gain +584.1
First return >= 10 30 epochs earlier

Single-seed IRIS/Pong snapshot; not the final benchmark table.

What this seed supports

Annealed SLS reduces the mid-training collapse window and improves sample-efficiency metrics under matched CE conditions.

What it does not claim

The current claim is not a final-return win. CE remains slightly better in the final tail on this first seed.

Why annealing matters

Fixed SLS is the negative-control ablation: it can stabilize early training, but its asymptotic failure motivates annealing the smoothing mass back to CE.

Two contributions, separated on purpose

Method first, application second

Annealed SLS

Structured smoothing allocates probability mass to nearby tokens under a tokenizer-defined metric. The smoothing mass is annealed to zero, so late training is exactly the CE baseline.

Geometry Dash

The application system combines FSQ tokenization, a causal transformer world model, and a small CNN actor-critic trained through BC plus PPO entirely in dreams.

Objective

A soft target with geometry

One-hot cross-entropy treats every wrong token equally. SLS replaces the one-hot target with a kernel over token distance, so near-miss alternatives receive useful supervision and distant tokens receive negligible mass.

$$q_t(j \mid i) \;\propto\; \varepsilon_t\, k(d(i,j)), \qquad k(d) = e^{-d^{2}/2\sigma^{2}}.$$

Application system

Real-time Vision-Model-Controller

Sharp discrete dreams

FSQ levels [8, 5, 5, 5] produce 1000 implicit codes on an 8x8 token grid.

Control in imagination

BC warm-starts the actor-critic, then PPO fine-tunes it in autoregressive dreamed rollouts.

Level continuations

Real gameplay prefixes can seed action-conditioned visual rollouts of plausible future segments.

30 FPS deployment

The full loop runs in about 15 ms per frame on an RTX 2060 SUPER, deployed at 30 FPS for capture stability.
