Current evidence

The application is the main result

DashVMC uses an FSQ tokenizer, an action-conditioned transformer world model, and a lightweight actor-critic trained in imagined rollouts before live deployment. SLS is retained as a Geometry Dash/FSQ-motivated design choice, not as the headline claim.

Deployment rate 30 FPS
Pipeline latency ~15 ms
Token grid 8x8

Geometry Dash system snapshot; final paper table will report frozen evaluation metrics.

What the paper claims

A compact discrete world model pipeline can support real-time Geometry Dash control and visual future rollouts.

What SLS claims

SLS is a scoped FSQ-neighbour prior motivated by Geometry Dash, not a proven general replacement for CE.

What IRIS showed

Annealed SLS had partial stability signals on Pong but did not robustly outperform CE across five seeds.

Two contributions, separated on purpose

Application first, diagnostic second

Geometry Dash system

FSQ tokenization, causal action-conditioned dynamics, and a controller trained with BC plus PPO in dreams.

SLS diagnostic

A metric-aware FSQ smoothing prior motivated by the application, with IRIS/Pong reported as a negative/conditional transfer test.

Objective

A scoped soft target with geometry

One-hot cross-entropy treats every wrong token equally. SLS replaces the one-hot target with a kernel over token distance, so near-miss alternatives receive useful supervision and distant tokens receive negligible mass.

$$q_t(j \mid i) \;\propto\; \varepsilon_t\, k(d(i,j)), \qquad k(d) = e^{-d^{2}/2\sigma^{2}}.$$

Application system

Real-time Vision-Model-Controller

Sharp discrete dreams

FSQ levels [8, 5, 5, 5] produce 1000 implicit codes on an 8x8 token grid.

Control in imagination

BC warm-starts the actor-critic, then PPO fine-tunes it in autoregressive dreamed rollouts.

Level continuations

Real gameplay prefixes can seed action-conditioned visual rollouts of plausible future segments.

30 FPS deployment

The full loop runs in about 15 ms per frame on an RTX 2060 SUPER, deployed at 30 FPS for capture stability.

Research status

What is locked, what is still running

Locked: Geometry Dash as the real-time application showcase.

Diagnostic: IRIS/Pong did not validate annealed SLS as a robust CE replacement.

Scoped: fixed SLS remains a Geometry Dash/FSQ design choice, not the main paper claim.
